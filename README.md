# ポケコン PB-100用ゲーム 『平城京エイリアン　heijo』

## 動作機種
CASIO PB-100系実機/PB-Simulator（PocketBASIC-Simulator）<br>
※実機の場合、要1KB増設

## 開発言語
BASIC

## セットアップ

本体へ、以下の順でセットアップします。

### CASIO PB-100シミュレータ PB-Simulatorをお使いの場合

* PB-Simulatorを起動します。
* `リストを開く`をクリックし、プログラムファイル`heijo_pbsim.bas`を読み込みます。

### 実機をお使いの場合

現在、プログラム音声ファイルは公開していません。<br>
よって、プログラムファイル`heijo_pb100.bas`を、何らかの方法でプログラム音声ファイルに変換して転送するか、プログラムリストを手入力する必要があります。<br>
プログラムリストを手入力される場合、プログラム中のエスケープシーケンスを、以下の表に従って置き換えてください。<br>
エスケープシーケンスの詳細については、[Pocket BASIC Simulatorのサイト](http://p6ers.net/bernie/develop/pbsim.html)をご確認ください。

| エスケープシーケンス | 置き換え後の文字 |
|----------------------|------------------|
| \LE                  | ≦               |
| \GE                  | ≧               |
| \LA                  | ←               |
| \RA                  | →               |
| \DT                  | ・               |
| \DV                  | ÷               |
| \TR                  | △               |
| \CI                  | ◯               |
| \BX                  | ■               |
| \CR                  | ×               |
| \NE                  | ≠               |
| \PI                  | π               |

初回のみ、`DEFM 12`と入力・実行してください。

## 起動方法

実機の場合、`RUN`と入力・実行します。<br>
PB-Simulatorの場合、`リストを実行する`をクリックします。

## ゲームのジャンル

戦略系穴掘りアクション<br>

## ストーリー

なんと見事な平城京（710年）。<br>
天平の都・平城京に、どう考えても時代を間違えたエイリアンが出現した。<br>

都の警備を担う衛門府が出動するが、ここで深刻な事実が判明。<br>
プレイヤーは弱い。とにかく弱い。<br>
剣も槍も重すぎて、持った瞬間に腰を痛める。<br>

残された装備は、なぜか正式支給された一本のスコップ。<br>
衛門府は結論を出す。<br>
戦は腕力ではない。穴である。<br>

プレイヤーは今日も都を守るため、掘って、誘って、落として、埋める。<br>
平城京の平和は、あなたの筋力ではなく、穴の完成度にかかっている。<br>

## ゲームのルール

プレイヤーは、平城京を守る衛門府です。<br>
`左右`で移動します。<br>

`Zキー`で地面に穴を掘ります。<br>
`Xキー`で穴を埋めます。<br>
穴を掘るのも埋めるのも、あなたの仕事です。<br>
ステージには壁があります。<br>
壁は非常にかたく、越えることはできません。<br>
都の区画整理は完璧です。<br>

エイリアンはとても強く、直接触れると捕まります。<br>
捕まると喰べられてしまい、昇天します（ミス扱い）。<br>
人生、逃げるが勝ちです。<br>

３回捕まると、ゲームオーバーとなります。<br>
都の平和と、あなたの努力が報われます。<br>

## 操作方法

### 《プログラム起動時》　（PB Simulator用プログラムファイルのみ）

`0:PB 1:SIM=`と表示された時の操作

| キー                       | 役割                                                                                           |
|----------------------------|------------------------------------------------------------------------------------------------|
| `0キー`を押下後に`EXEキー` | 実機モードでゲームスタートします。<br>標準のキャラクターが表示され、音は再生されません。       |
| `1キー`を押下後に`EXEキー` | PB-Simulatorモードでゲームスタートします。<br>独自のキャラクターが表示され、音が再生されます。 |

### 《ゲーム》

| キー           | 役割                           |
|----------------|--------------------------------|
| `４`・`６キー` | 衛門府を左右に操作します。<br>左右端を超えて移動すると、反対側へ移動します。 |
| `Zキー`        | 地面に穴を掘ります。           |
| `Xキー`        | 掘った穴を埋めます。           |

## キャラクター紹介

### 《プレイヤー（衛門府）》

あなたです。<br>
平城京を守るために配属された、衛門府の一員です。<br>

とても弱いので、剣も槍も使えません。<br>
走る、掘る、埋める、それだけが取り柄です。<br>
足は速くありませんが、仕事は地道です。<br>

エイリアンに触れると捕まってしまいます。<br>
捕まると喰べられて昇天します。<br>
勇気より距離感が大切です。<br>

### 《エイリアン》

平城京の地下から出てきた、よく分からない存在です。<br>
とにかく強く、直接倒すことはできません。<br>

追いかけるのは得意ですが、足元はあまり見ていません。<br>
穴に落ちると、動かなくなります。<br>

数が増えると、一気に危険になります。<br>
近づかせないことが、最大の対策です。<br>

## スコア

| 行動                   | 得点                 |
|------------------------|----------------------|
| 穴を掘る               | １点                 |
| エイリアンを穴に落とす | １０点               |
| エイリアンを穴に埋める | １００点             |

## 終了方法

実機の場合、本体の`STOPキー`を押すか、電源を切断してください。<br>
PB-Simulatorの場合、ウインドウを閉じてください。

## 変数表

###  PB Simulator

| 変数 | 内容                                                              |
|------|-------------------------------------------------------------------|
| A    | サブルーチン引数用                                                |
| B    | 前回のプレイヤーの方向                                            |
| C    | カウンタ                                                          |
| E    | 敵のX座標                                                         |

| I    | 前回のプレイヤーのX座標                                           |
| J    | 前回の敵のX座標                                                   |
| M    | 最大穴掘り回数（デフォルトは3回 ※本来5回だがテンポが悪くなる）   |
| O    | 実行機種<br>
|      | 0=実機 1=PB-SIM                                                   |
| P    | プレイヤー残り数                                                  |
| R    | 面                                                                |
| S    | ステータス<br>
|      | 0=通常 1～10=敵が穴に落ちている 11=穴から這い上がる               |
| T    | 得点                                                              |
| W    | ワーク用                                                          |
| X    | プレイヤーのX座標                                                 |
| Z(n) | 画面穴情報 n:X座標0~11<br>
|      | 0=空白 1=穴1 2=穴2 3=穴3 4=穴4 5=穴5 （最大穴掘り回数５回の場合） |
|      | 0=空白 1=穴1 2=穴2 3=穴3 （最大穴掘り回数３回の場合）             |
| $    | 各種キャラクター<br>
|      | 01バイト目=プレイヤー左向き1<br>
|      | 02バイト目=空白<br>
|      | 03バイト目=プレイヤー右向き1<br>
|      | 04バイト目=空白<br>
|      | 05バイト目=プレイヤー左向き2<br>
|      | 06バイト目=空白<br>
|      | 07バイト目=プレイヤー右向き2<br>
|      | 08バイト目=穴1<br>
|      | 09バイト目=穴2<br>
|      | 10バイト目=穴3<br>
|      | 11バイト目=穴4（最大穴掘り回数５回の場合のみ）<br>
|      | 12バイト目=穴5（最大穴掘り回数５回の場合のみ）                    |
